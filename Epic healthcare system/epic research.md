# Epic Research

---

## 📌 Topic 1 — What Epic Is

Epic is a computer system hospitals use to keep patients' medical records. It is the **most popular one in US hospitals**, used by roughly **4 in 10** of them.

Instead of paper files, everything about a patient is stored digitally:
- Past illnesses
- Medicines
- Test results
- Appointments
- Bills

---

## 📌 Topic 2 — Why Hospitals Buy It

Hospitals pick Epic because it puts everything in one place and feels like the low-risk choice.

| Reason | Explanation |
|---|---|
| Everything in one place | Without it, a hospital might use many different systems that don't talk to each other |
| Everyone sees the same information | Doctors, nurses, the lab and the pharmacy all work from the same record |
| Safe, popular choice | Many big hospitals already use it, so it feels low-risk |
| Hospitals can share records | If a patient goes to another hospital that uses Epic, their information can follow them |

> **Downside:** It's expensive and hard to set up.

---

## 📌 Topic 3 — How It Helps Doctors

Epic saves doctors time and keeps the whole care team on the same page, so fewer things get missed or repeated.

- They can see a patient's **full history quickly** instead of searching for papers
- It **warns them about problems**, like a medicine that clashes with another one
- When a doctor orders a test or medicine, it goes **straight to the lab or pharmacy**

> **Note:** One common complaint is that doctors spend a lot of time typing notes into it, so newer tools that write the notes for them are being added.

---

## 📌 Topic 4 — What Staff Dislike About Epic

The main complaints are about time, usability and cost.

| Complaint | Detail |
|---|---|
| Too many clicks | Staff spend more time on the screen than with patients |
| Confusing screens | Things are hard to find, the program can lag, and users must remember button names |
| Too much paperwork | Leads to staff burnout |
| Very expensive | Hospitals in Boston spent **$1.2 billion** on setup |
| Hard to set up | One hospital saw fewer patients while staff were learning the system |

---

## 📌 Topic 5 — How Epic Connects With Other Companies

Epic does let others connect, but **Epic decides how**. It works in two ways:

### Way 1 — Other Companies' Apps Plug Into Epic

- Epic gives app makers a standard way to connect, so an app can open right inside Epic's screens
- App makers must join Epic's program called **Showroom** and pay:
  - ~**$500/year** for basic membership
  - ~**$1,900/year** for another level of membership
- Each hospital must individually approve an app — so an app maker can't connect once and work everywhere
- One expert described it as: **"20% development, 80% negotiation"**

### Way 2 — Epic Shares Patient Records With Other Hospitals

- Epic has a tool called **Care Everywhere** — a doctor can use it to request records from another hospital
- Epic says about **half** of these requests go to hospitals that don't use Epic *(Epic's own figure)*
- Epic joined a national sharing network called **TEFCA**, connecting **1,000+ hospitals**
- It doesn't always work perfectly — when records start outside Epic, there can still be gaps
